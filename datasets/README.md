# Dataset collection for a team detector

Capture your own images using the intended mounting and resolution and obtain permission for any borrowed image. Avoid collecting identifiable people and remove hidden location metadata from shared images. Record a license with each shareable batch.

Keep each recording session wholly within train, validation or test. Include fully visible and partly hidden objects at multiple ranges, empty scenes, similar tape and uneven illumination. Annotate every visible target using the training tool's box convention. Keep an empty label file or a clearly marked negative entry for empty frames.

Recommended manifest columns are path, session, split, scene, lighting, license, resolution, label path, and review status. Keep a stable class order through training, export and camera configuration. Use physical BIOBUZZ pieces or label a substitute as such. There are no bundled game photos, trained weights or claimed metrics.

See [training and deployment](https://fusingchart.github.io/ftc-visionstack/course/lesson-10-3/) for the hardware evaluation procedure.
