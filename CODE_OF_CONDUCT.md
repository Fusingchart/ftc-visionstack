# Code of conduct

Treat students, mentors and other contributors with respect. Critique decisions, examples and evidence directly. Help newcomers participate, credit work you reuse, and preserve others' privacy. Harassment, discrimination, threats, impersonation and disclosure of private information are unacceptable.

For a public content or behavior issue that can be described without exposing personal information, contact a repository maintainer through GitHub. For sensitive incidents, use GitHub's private report or abuse channels. Maintainers may remove content, close discussions or restrict participation to keep the project welcoming.
