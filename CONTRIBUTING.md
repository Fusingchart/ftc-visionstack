# Contributing

1. Fork the repository and create a topic branch.
2. Edit the appropriate file under `content/`, `site/`, `ftc-examples/`, or `pipelines/`.
3. Run `npm run lint` and `npm test`.
4. Open a pull request with the affected URL or OpMode, the expected behavior, and the checks you ran.

For a correction, cite the vendor documentation or current FIRST manual section. For a new robot example, include the FTC SDK version, camera firmware, hardware map, camera axes, units, failure behavior, and an independent acceptance test. Include the raw evidence for any measured result, with personal information removed. State which checks were compile-only, simulated, bench hardware, or competition field.

Use a [bug report](https://github.com/Fusingchart/ftc-visionstack/issues/new?template=problem.yml) for a reproducible issue. Attach only logs and media you are allowed to share. Follow the [code of conduct](CODE_OF_CONDUCT.md).
